## EC3 - parte 1
Esta primera parte de la EC3 puede ser realizada de manera individual o en grupos de hasta 2 personas. Esta tarea constituye 8 puntos de la EC3.

1. [4 puntos] Utilizando optimización de trayectorias (cualquier método), considerar una configuración en la que un robot cuadrúpedo tiene en frente un obstáculo alto que no puede atravesar caminando. El robot debe saltar para poder "pasar" el obstáculo. Generar el movimiento para realizar este salto. Se puede utilizar el modelo completo de un robot cuadrúpedo o un modelo simplificado (SRBM) seguido de cinemática para la posición de las patas.


2. [4 puntos] Generar un movimiento libre pero "interesante" utilizando optimización de trayectorias. Puede ser para un robot aéreo, un robot cuadrúpedo, un robot humanoide o algún otro tipo de robot. Se calificará considerando la complejidad del movimiento
No es necesario el uso de un simulador como PyBullet o algún otro, pero se puede utilizar si se considera apropiado. Es suficiente con realizar la simulación utilizando el modelo dinámico en Python.

Se debe presentar un pequeño reporte en el cual se muestre la formulación matemática del problema para ambos casos [1.5 puntos], algunas figuras que muestren el resultado [1.5 punto] y una animación del movimiento [1 punto]. 
Se debe también adjuntar el código utilizado para cada una de las partes, con todos los archivos necesarios. El código debe poder "correrse" para obtener resultados similares a los mostrados; de lo contrario, no se considerará válida la pregunta respectiva.
